# Remotive Job Listings Dashboard

A Python and Streamlit project that collects remote job listings from the Remotive public API, stores the results in CSV format, and presents the data in an interactive dashboard.

This repository is based on a project focused on automating job-data collection and making the results easier to explore through summary metrics, charts, a world map, and a full table.

> The Python files in this portfolio repository are a cleaned reconstruction of the implementation documented in the original course report and code screenshots. They preserve the reported architecture and behavior while improving error handling, organization, and readability.

## Project Overview

The application follows a simple data flow:

```text
Remotive API -> scraper.py -> jobs.csv -> dashboard.py
```

The scraper retrieves remote-job data from the Remotive API and saves selected fields to `jobs.csv`. The Streamlit dashboard then loads that CSV and visualizes the data.

## Features

- Collects remote job listings from the Remotive public API
- Extracts job title, company, location, category, job type, salary, publication date, and job link
- Records the time each scrape is performed
- Removes duplicate listings before saving
- Stores results in CSV format
- Displays total jobs and unique companies
- Shows an approximate world map of job locations
- Displays a jobs-by-location bar chart
- Displays a full job-listing table

## Installation

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Usage

### 1. Collect Job Data

```bash
python scraper.py
```

This creates or refreshes `jobs.csv` using data from the Remotive API.

### 2. Launch the Dashboard

```bash
streamlit run dashboard.py
```

Streamlit will start the local dashboard and open it in your browser.

## Dashboard Output

The documented project demo collected 21 job listings across categories including software development, AI/ML, marketing, and customer service. The dashboard made it easier to identify patterns in job locations, companies, and available roles.

The project report noted that many listings in the demo were concentrated in the United States and that location data was not always precise.

## Limitations

- Job-location values are free-form and do not always map cleanly to geographic coordinates.
- The project depends on the availability and structure of the Remotive API.
- The included location mapping is approximate rather than a full geocoding solution.
